Lecture 1 — Prerequisites check (Tier 0)#

Run this notebook once before delivering Lecture 1 to verify your environment has everything needed.

Two ways to do the same check:

  • From the command line — python env/check_lecture_env.py (in the workshop folder, with the conda env activated)

  • From here — Run All ▶ on this notebook. Same checks, same fix suggestions, but inside JupyterLab or Notebook 7.

Three tiers of dependencies:

  • Tier 0 — view the pre-built static slide deck. Needs only a browser. This notebook is for confirming Tier 1+ but the static deck works regardless.

  • Tier 1 — rebuild the deck from source via python build_lecture_notebook.py. Needs jupyter, nbconvert>=7, matplotlib, numpy, scipy.

  • Tier 2 — present live with executable code cells. Needs RISE (rise for classic Notebook 6.x) or jupyterlab_rise for JupyterLab 4.x / Notebook 7.

This check covers Tier 1 and Tier 2 dependencies. Lab notebook deps (Cellpose, Noise2Void, Segment Anything, etc.) are checked separately by notebooks/00_setup_self_check.ipynb.

Setup helpers#

Run this cell first. It defines the helper functions every check below uses.

import importlib
import importlib.metadata
import platform
import sys

def show_runtime():
    print(f"Platform : {platform.platform()}")
    print(f"Python   : {sys.version.split()[0]}  ({sys.executable})")

def check_module(module_name, why, fix, required=True, min_version=None):
    """Try to import a module; report status, version, and fix if missing."""
    try:
        mod = importlib.import_module(module_name)
        version = getattr(mod, "__version__", None)
        if version is None:
            try:
                version = importlib.metadata.version(module_name)
            except importlib.metadata.PackageNotFoundError:
                version = "unknown"
        if min_version:
            try:
                cur = tuple(int(x) for x in str(version).split(".")[:2])
                mn  = tuple(int(x) for x in min_version.split(".")[:2])
                if cur < mn:
                    print(f"⚠  {module_name:<22} version {version} < required {min_version}")
                    print(f"   Why : {why}")
                    print(f"   Fix : {fix}")
                    return False
            except ValueError:
                pass
        print(f"✓  {module_name:<22} {version}")
        return True
    except ImportError as e:
        symbol = "✗" if required else "○"
        marker = "REQUIRED" if required else "optional"
        print(f"{symbol}  {module_name:<22} NOT INSTALLED ({marker})")
        print(f"   Why : {why}")
        print(f"   Fix : {fix}")
        return False

show_runtime()

Tier 1 — required for rebuilding the lecture#

If any of these fail, you cannot run python build_lecture_notebook.py to rebuild the deck. The pre-built static .slides.html deck still works without them.

# numpy — used by build_figures.py and the in-slide demo cells
check_module(
    "numpy",
    why="Used by build_figures.py to construct the 14 lecture figures and by the in-slide demo cells.",
    fix="conda install -c conda-forge numpy   # or:  %pip install numpy",
)

# scipy — used by some figure helpers (gaussian_filter for the synthetic visuals)
check_module(
    "scipy",
    why="Used by some build_figures.py helpers (gaussian_filter for the synthetic image visuals).",
    fix="conda install -c conda-forge scipy   # or:  %pip install scipy",
)

# matplotlib — authors all 14 PNG figures embedded in the lecture
check_module(
    "matplotlib",
    why="Authors the 14 PNG figures embedded in the lecture as base64 data URLs.",
    fix="conda install -c conda-forge matplotlib   # or:  %pip install matplotlib",
)

# jupyter — provides the notebook front-end you're running this in
check_module(
    "jupyter",
    why="Provides the notebook front-end. You're running it now if this cell executes.",
    fix="conda install -c conda-forge jupyterlab   # or:  %pip install jupyterlab",
)

Tier 2 — optional, for live RISE presentation#

These let you present the lecture with live executable code cells during the talk. If you only use the static .slides.html, you don’t need them.

Pick one based on your front-end:

  • rise for classic Jupyter Notebook 6.x (legacy)

  • jupyterlab_rise for JupyterLab 4.x or Notebook 7 (most modern setups)

check_module(

    required=False,

Optional sanity check — try a tiny matplotlib render#

If matplotlib imported above, the cell below confirms it can actually produce a figure (some headless environments can’t).

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 4 * np.pi, 200)
fig, ax = plt.subplots(figsize=(5, 2.5))
ax.plot(x, np.sin(x), color='#00adee', linewidth=2)  # brand cyan
ax.set_title("matplotlib renders correctly")
ax.set_xticks([]); ax.set_yticks([])
plt.tight_layout()
plt.show()

What to do next#

  • All ✓ in Tier 1? You can rebuild the lecture: python lectures/01_intro_ai_imaging/build_lecture_notebook.py.

  • All ✓ in Tier 2? You can present live with executable cells. Open lecture.ipynb in JupyterLab and click the RISE icon (top-right toolbar). Press S for speaker view once the slideshow is open.

  • Failures in Tier 1? Run the suggested conda install / %pip install commands above, then re-run this notebook.
