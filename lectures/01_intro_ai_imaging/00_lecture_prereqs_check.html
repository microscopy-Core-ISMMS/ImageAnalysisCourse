Lecture 1 — Overview & Setup#

This page is the Lecture 1 landing page. It covers what’s in the folder, how to view / present / edit the lecture, and an environment self-check you can run before delivering.

The lecture is split across two artifacts:

  • lecture_slides.html — the static slide deck. Open in any browser; no install needed. This is the file most attendees see.

  • lecture.ipynb — the source notebook. Open in Jupyter / Colab to edit or to run the four interactive demo cells. Click the Open in Colab badge above to launch.

How to view, present, and edit#

View the slides#

Open lecture_slides.html in any modern browser (Chrome, Firefox, Safari, Edge). Slides advance with arrow keys (right / down for next, left / up for previous). Press f for fullscreen, s for speaker notes view.

The HTML is fully self-contained except for one CDN dependency (reveal.js itself, loaded from unpkg.com).

Present live from the notebook#

Two options:

  1. From the exported HTML. Open lecture_slides.html in a browser. Simplest path, works everywhere.

  2. From the notebook with RISE. In JupyterLab or Notebook 7 with the jupyterlab-rise extension installed, open lecture.ipynb and click the slideshow toggle. Live code cells become runnable during the presentation. RISE does not currently work in Google Colab — for live presentation use a local Jupyter install.

Run interactive code cells#

Click the Open in Colab badge at the top of this page (or open lecture.ipynb in JupyterLab) and run cells normally. The lecture has four runnable demonstration cells (setup check, train / val / test split, Cellpose-style result viewer, metrics-vs-biology scatter). The slideshow does not paginate in Colab — for the slide experience, view lecture_slides.html instead.

Edit and rebuild#

The lecture is authored in Python via build_lecture_notebook.py. Edit the script, then re-run it:

python build_lecture_notebook.py

This regenerates lecture.ipynb. To re-export the HTML slides:

jupyter nbconvert --to slides lecture.ipynb --SlidesExporter.reveal_theme=white --output lecture_slides

You can edit lecture.ipynb directly if you prefer; the build script and the notebook produce equivalent output, but the script is easier to diff and review.

Verification, citations, and hallucination flags#

Every cited work in the lecture carries an inline verification flag:

  • ✓ verified via web search this session

  • ✏ corrected — initial training-knowledge claim was wrong; entry reflects correction

  • ⚠ uncertain — drawn from training, not directly verified; sanity-check before publication

  • ❓ synthesis — interpretation or framing, not a specific citation

Flags appear inline next to citation chips on each slide and in the bibliography slide at the end. Full audit trail is in verification_log.md (linked under Extras in the sidebar).

Caveat. Verification used web-search metadata, not full-text PDFs. All references should be cross-checked against published source articles before any external delivery — search-result metadata can lag, mislabel, or contain errors.

Offline / air-gapped use#

The exported HTML loads reveal.js from unpkg.com. For a strictly air-gapped deck:

jupyter nbconvert --to slides lecture.ipynb --SlidesExporter.reveal_theme=white \
                  --output lecture_slides_offline --reveal-prefix=reveal.js

Then download reveal.js into a local reveal.js/ folder next to the HTML.

Prerequisites check (Tier 0)#

Run this notebook once before delivering Lecture 1 to verify your environment has everything needed.

Two ways to do the same check:

  • From the command line — python env/check_lecture_env.py (in the workshop folder, with the conda env activated)

  • From here — Run All ▶ on this notebook. Same checks, same fix suggestions, but inside JupyterLab or Notebook 7.

Three tiers of dependencies:

  • Tier 0 — view the pre-built static slide deck. Needs only a browser. This notebook is for confirming Tier 1+ but the static deck works regardless.

  • Tier 1 — rebuild the deck from source via python build_lecture_notebook.py. Needs jupyter, nbconvert>=7, matplotlib, numpy, scipy.

  • Tier 2 — present live with executable code cells. Needs jupyterlab_rise for JupyterLab 4.x / Notebook 7, or rise for classic Notebook 6.x.

This check covers Tier 1 and Tier 2 dependencies. Lab notebook deps (Cellpose, Noise2Void, Segment Anything, etc.) are checked separately by notebooks/00_setup_self_check.ipynb.

Setup helpers#

Run this cell first. It defines the helper functions every check below uses.

import importlib
import importlib.metadata
import platform
import sys

def show_runtime():
    print(f"Platform : {platform.platform()}")
    print(f"Python   : {sys.version.split()[0]}  ({sys.executable})")

def check_module(module_name, why, fix, required=True, min_version=None):
    """Try to import a module; report status, version, and fix if missing."""
    try:
        mod = importlib.import_module(module_name)
        version = getattr(mod, "__version__", None)
        if version is None:
            try:
                version = importlib.metadata.version(module_name)
            except importlib.metadata.PackageNotFoundError:
                version = "unknown"
        if min_version:
            try:
                cur = tuple(int(x) for x in str(version).split(".")[:2])
                mn  = tuple(int(x) for x in min_version.split(".")[:2])
                if cur < mn:
                    print(f"⚠  {module_name:<22} version {version} < required {min_version}")
                    print(f"   Why : {why}")
                    print(f"   Fix : {fix}")
                    return False
            except ValueError:
                pass
        print(f"✓  {module_name:<22} {version}")
        return True
    except ImportError as e:
        symbol = "✗" if required else "○"
        marker = "REQUIRED" if required else "optional"
        print(f"{symbol}  {module_name:<22} NOT INSTALLED ({marker})")
        print(f"   Why : {why}")
        print(f"   Fix : {fix}")
        return False

show_runtime()

Tier 1 — required for rebuilding the lecture#

If any of these fail, you cannot run python build_lecture_notebook.py to rebuild the deck. The pre-built static .slides.html deck still works without them.

# numpy — used by build_figures.py and the in-slide demo cells
check_module(
    "numpy",
    why="Used by build_figures.py to construct the 14 lecture figures and by the in-slide demo cells.",
    fix="conda install -c conda-forge numpy   # or:  %pip install numpy",
)

# scipy — used by some figure helpers (gaussian_filter for the synthetic visuals)
check_module(
    "scipy",
    why="Used by some build_figures.py helpers (gaussian_filter for the synthetic image visuals).",
    fix="conda install -c conda-forge scipy   # or:  %pip install scipy",
)

# matplotlib — authors all 14 PNG figures embedded in the lecture
check_module(
    "matplotlib",
    why="Authors the 14 PNG figures embedded in the lecture as base64 data URLs.",
    fix="conda install -c conda-forge matplotlib   # or:  %pip install matplotlib",
)

# jupyter — provides the notebook front-end you're running this in
check_module(
    "jupyter",
    why="Provides the notebook front-end. You're running it now if this cell executes.",
    fix="conda install -c conda-forge jupyterlab   # or:  %pip install jupyterlab",
)

# nbconvert — renders the lecture .ipynb to the static reveal.js .slides.html
check_module(
    "nbconvert",
    why="Renders the lecture .ipynb to the static reveal.js .slides.html that the build script ships.",
    fix="conda install -c conda-forge 'nbconvert>=7,<8'   # or:  %pip install 'nbconvert>=7,<8'",
    min_version="7.0",
)

Tier 2 — optional, for live RISE presentation#

These let you present the lecture with live executable code cells during the talk. If you only use the static .slides.html, you don’t need them.

Pick one based on your front-end:

  • rise for classic Jupyter Notebook 6.x (legacy)

  • jupyterlab_rise for JupyterLab 4.x or Notebook 7 (most modern setups)

# rise — classic Notebook 6.x RISE
check_module(

        "conda install -c conda-forge 'jupyterlab_rise>=0.40,<1.0'   "

Optional sanity check — try a tiny matplotlib render#

If matplotlib imported above, the cell below confirms it can actually produce a figure (some headless environments can’t).

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0, 4 * np.pi, 200)
fig, ax = plt.subplots(figsize=(5, 2.5))
ax.plot(x, np.sin(x), color='#00adee', linewidth=2)  # brand cyan
ax.set_title("matplotlib renders correctly")
ax.set_xticks([]); ax.set_yticks([])
plt.tight_layout()
plt.show()

What to do next#

  • All ✓ in Tier 1? You can rebuild the lecture: python lectures/01_intro_ai_imaging/build_lecture_notebook.py.

  • All ✓ in Tier 2? You can present live with executable cells. Open lecture.ipynb in JupyterLab and click the RISE icon (top-right toolbar). Press S for speaker view once the slideshow is open.

  • Failures in Tier 1? Run the suggested conda install / %pip install commands above, then re-run this notebook.

  • Static deck-only delivery? No further action — the pre-built lecture_slides.slides.html works in any browser, no Jupyter needed.
