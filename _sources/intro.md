# AI for Microscopy Image Analysis

A one-day hands-on workshop for biologists with technical expertise. This book is the workshop's permanent reference: every page, every notebook, every link survives the workshop day for self-paced study afterward.

## How this book is organized

The sidebar on the left is the table of contents. Use it to navigate between sections. The outline on the right shows the structure of the current page. The search bar at the top searches every page in the book.

The workshop runs in this order:

1. **Workshop overview** — schedule, prerequisites, resources, handout.
2. **Ramp-up evening (optional)** — covers Python and image-data basics for attendees who need a runway before the workshop.
3. **Lecture 1** — *AI for scientific image analysis: what works, what doesn't, and why*. The morning lecture's structured outline, slides reference, speaker cues, and verification log.
4. **Lecture 2** — *Walking the day*. The bridge talk between morning lecture and afternoon labs.
5. **Lab notebooks** — five labs (00–03b) plus an additional community-platforms catalog (04).
6. **Setup and data** — environment configuration and dataset references.

## What's interactive

Every notebook in the book is a real Jupyter notebook. You can:

- **Read it directly** here — the code cells display with their outputs (where present).
- **Open it in Colab** — there's a launch button at the top of each notebook page. The notebook opens in Colab with the runtime ready.
- **Run live in this page** — for shorter computations, the *Live Code* button at the top runs cells in your browser via Binder.

The lab notebooks are designed for the Colab path during the workshop itself.

## What's not interactive

The lecture slides (reveal.js) live as exported HTML and are linked from the relevant lecture pages. They render as a presentation, not as part of this book — open them in a separate tab during a live session.

## Where to start

If you've come here for the first time and want to read this book, start with the [schedule](schedule) and [prerequisites](prerequisites). If you've already attended the workshop and want to continue learning, go to the [resources](resources) and [handout](handout) pages — those are the post-workshop reference.
