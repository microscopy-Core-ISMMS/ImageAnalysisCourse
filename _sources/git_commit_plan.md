
### 6. Push to GitHub

If your local default branch isn't `main` (rare on a fresh clone), rename:

```bash
git branch -M main
```

Push the first time with `-u` to set upstream tracking:

```bash
git push -u origin main
```

LFS files will be transferred automatically. Expect this push to take a minute or two — the `day-2-fiji/Exercise Images/` folder is ~58 MB across 23 files.
